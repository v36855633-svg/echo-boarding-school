# Интернат Эхо (Echo Boarding School)

2D top-down хоррор со стелсом, вдохновлённый играми серии Granny, но с уникальной сюжетной линией и механиками.

## Управление

- **WASD / стрелки** — движение
- **Shift** — бег (тратит стамину)
- **Ctrl** — красться (медленно, но тихо)
- **E** — взаимодействовать с предметами
- **Пробел** — спрятаться в укрытие / выйти из него
- **G** — использовать граммофон (если он есть)
- **R** — перезапуск игры (после поражения/победы)

## Установка и запуск в Termux

1. Установите Python и Kivy:
```

pkg install python
pip install kivy

```

2. Скачайте все файлы проекта в одну папку.

3. Запустите игру:
```

python main.py

```

## Особенности

- Цикл дня и ночи: днём Смотрительница патрулирует, ночью становится опаснее.
- Система шума: бег и ходьба привлекают внимание.
- Укрытия: прячьтесь в шкафах и за столами.
- Граммофон: временно вводит Смотрительницу в транс.
- 4 главы с возрастающей сложностью.
- Сюжет о поиске пропавшего брата и противостоянии безумной Смотрительнице.

## Примечание

Код является каркасом и может быть расширен. Визуализация упрощена для совместимости с мобильными устройствами.
